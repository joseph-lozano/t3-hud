# T3 HUD

Vocabulary for the hotkey-accessible wrapper around the T3 Code interface.

## Language

**HUD**:
The view of T3 Code that the user can summon and dismiss with a hotkey.

**Dismiss**:
Hide the T3 view while keeping its floating icon available. Whether any underlying processes stop is a separate lifecycle decision.

**Floating icon**:
The on-screen control that toggles the T3 view's visibility.

**Thread**:
A conversation in T3 Code that the user checks or continues through the HUD.

**Prompt**:
A message the user sends to T3 Code to start or continue work in a thread.
